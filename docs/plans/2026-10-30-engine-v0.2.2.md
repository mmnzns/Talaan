# Engine v0.2.2: Talaan moves to the shared engine — task plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax.
> Model: **Sonnet builds every task** (code, tests, bulk edits, builds, benches). Opus briefs, reviews each task and
> decides. Branch `engine-v0.2.2` (from `origin/main` at 1.1.1). Nothing in this plan pushes to `main`, tags or
> publishes without Miguel's OK.

**Goal:** Talaan runs its local AI, speech, voice detection and speaker separation through voice-engine v0.2.2 and
keeps its models in the shared folder, with no loss of speed (Whisper Turbo about 19.9x on Metal) and a clean
one-time move of the models people already have.

**Architecture:**
- **Models:** one `SharedStore` per run, opened at start in a new `src-tauri/src/models.rs` (`Models`), which also
  runs `move_in` and `collect`. Everything that used `ModelStore`/`Location`/`download.rs`/`relocate.rs` asks
  `Models` instead. The catalog is the engine's (`voice_engine_models::catalog`); Talaan keeps only its order of
  recommendation and its wording (i18n `settings.model_note_<id>`).
- **Speech:** Talaan's pipeline (`pipeline.rs`, `merge.rs`, `echo.rs`, `worker.rs`, `vad::shape`, `assign_speakers`)
  stays. Its `Engine`, `Detector` and `SpeakerSplitter` traits get engine-backed implementations: in process
  (`voice_engine_stt::load`, `vad::detect`, `diarize::load`) everywhere, plus `SttClient` (Vulkan helper with a
  processor helper behind it) for Whisper on the Windows card.
- **Local AI:** `voice_engine_client::LlmClient` replaces `LocalAi`, `helper.rs` and `talaan-llm-protocol`. Errors are
  matched on `EngineError`, never on text.
- **Graphics card:** on by default on the Mac; on Windows on by default only when
  `voice_engine_stt::discrete_card()` is `Some` (an `Err` or `None` = off). `gpu` is passed on every load and
  request. When the engine reports `fell_back`, the Status tab and the meeting's info say so.
- **Build:** helpers for releases come from `mmnzns/voice-engine/.github/workflows/build-helpers.yml@v0.2.2`. For
  development and tests, `src-tauri/llm` and `src-tauri/stt` stay as 3-line helper crates (`env_prefix: "TALAAN"`).

**Tech stack:** Rust 1.98 (edition 2024), Tauri 2, React 19 + TypeScript, Vitest, GitHub Actions.
voice-engine crates at `tag = "v0.2.2"`: `voice-engine-protocol`, `-models`, `-stt`, `-llm` (helpers only),
`-client`.

```rust
//! The models Talaan uses, kept in the shared folder by voice-engine ("Craft Concepts Digital/Models"), next to
//! Ensayo's and Parlato's. Talaan never deletes a model file itself: Delete is `release`, and the engine erases the
//! file once no app uses it.

use std::path::{Path, PathBuf};

use serde_json::Value;
use voice_engine_models::{catalog, App, ModelHandle, ModelInfo, SharedStore, Status, StoreError};

/// Talaan's recommended speech model.
pub const DEFAULT_SPEECH: &str = "whisper-turbo";
/// Talaan's recommended local AI model (long meetings); `qwen3.5-9b` is the optional larger one.
pub const DEFAULT_LOCAL_AI: &str = "qwen3.5-4b";
pub const VAD: &str = "vad";
pub const DIARIZATION: &str = "diarization";
pub const SEARCH: &str = "search";

pub struct Models {
    store: SharedStore,
}

impl Models {
    /// The shared folder, or `<test data>/shared-models` when `TALAAN_DATA_DIR` points Talaan at a test folder.
    /// `open_at` never moves anything in, so a test run can't touch the real models.
    pub fn open(test_data: Option<&Path>) -> std::io::Result<Models> {
        let store = match test_data {
            Some(dir) => SharedStore::open_at(App::Talaan, dir.join("shared-models"))?,
            None => SharedStore::open(App::Talaan)?,
        };
        Ok(Models { store })
    }

    /// First thing at start, before any model is opened or helper started: the one-time move from Talaan's old
    /// folders, then the engine's clean-up of models no app uses.
    pub fn start(&self, settings: Option<&Value>) {
        match self.store.move_in(&used_ids(settings)) {
            Ok(r) if !r.already_done => log::info!(
                "models moved into the shared folder: {} moved, {} linked, {} left for later",
                r.moved.len(), r.linked.len(), r.left_for_later.len()
            ),
            Ok(_) => {}
            Err(e) => log::warn!("couldn't move the models into the shared folder: {:?}", e.kind()),
        }
        if let Err(e) = self.store.collect() {
            log::warn!("couldn't tidy the shared models folder: {:?}", e.kind());
        }
    }

    pub fn root(&self) -> &Path {
        self.store.root()
    }
    pub fn store(&self) -> &SharedStore {
        &self.store
    }
    pub fn info(&self, id: &str) -> Option<&'static ModelInfo> {
        catalog::find(id)
    }
    pub fn status(&self, id: &str) -> Status {
        self.store.status(id)
    }
    /// The model's folder when every file is there.
    pub fn ready_dir(&self, id: &str) -> Option<PathBuf> {
        match self.store.status(id) {
            Status::Installed { dir, .. } => Some(dir),
            _ => None,
        }
    }
    /// Keep the returned handle for as long as the model is loaded.
    pub fn hold(&self, id: &str) -> Result<ModelHandle, StoreError> {
        self.store.hold(id)
    }
}

/// The model ids Talaan's settings point to. `move_in` records Talaan as a user of each.
pub fn used_ids(settings: Option<&Value>) -> Vec<&'static str> {
    let s = settings.cloned().unwrap_or(Value::Null);
    let speech = s["activeSpeechModel"]
        .as_str()
        .and_then(catalog::find)
        .filter(|m| m.is_speech())
        .map_or(DEFAULT_SPEECH, |m| m.id);
    let mut ids = vec![speech, VAD];
    if s["separateSpeakers"].as_bool().unwrap_or(true) {
        ids.push(DIARIZATION);
    }
    if matches!(s["summaryEngine"].as_str(), None | Some("local")) {
        ids.push(local_model_id(s["localModel"].as_str()));
    }
    ids
}

/// The `localModel` setting as a catalog id. 1.1 and earlier stored "recommended" or "larger".
pub fn local_model_id(setting: Option<&str>) -> &'static str {
    match setting {
        Some("larger") => "qwen3.5-9b",
        Some(id) => catalog::local_ai().find(|m| m.id == id).map_or(DEFAULT_LOCAL_AI, |m| m.id),
        None => DEFAULT_LOCAL_AI,
    }
}
```

```rust
        .filter(|p| !p.text.is_empty() && !voice_engine_stt::is_noise(&p.text))
```
